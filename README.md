## Descripción del Software

**Telemetría Pueble S.A.** es una aplicación de escritorio para el análisis de datos operativos de maquinaria agrícola. Permite cargar archivos de telemetría en formato JSONL y visualizar:

- Eficiencia operativa (modos Cosecha, Movimiento, Ralentí, Ralentí con Carga, Parada)
- Comparación entre múltiples máquinas
- Actividad diaria con línea de tiempo interactiva (Gantt)
- Series temporales de métricas numéricas
- Distribuciones de RPM, velocidad, carga del motor, extractor y presión
- Mapa GPS con trayectoria y datos operativos por punto
- Exportación de reportes en formato HTML
